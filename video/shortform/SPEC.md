# Chargis 숏폼 SPEC

GOAL:    공모전 숏폼 구성(Spot -> Solve -> Scene)으로, 운전자의 불편 3개에 앱이 하나씩 답하는 것을 보고
         "차가 어느 휴게소에서 몇 %까지 충전할지 먼저 알려 준다"를 기억한다.
OUTPUT:  HyperFrames, 1080 x 1920, 30 fps
TIME:    45 s x 30 = 1350 frames. 공모전 기준(30초~1분 세로). Spot 0-13 s / Solve 13-29 s / Scene 29-45 s.
         음악 bed: Spot은 낮게(0.05), 13 s 정적 0.2 s 뒤 Solve부터 본 볼륨(0.08).

LOOK:    앱 야간 통행권 그대로. 종이와 잉크.
         ground #0F0E0D (프레임 바탕), stock #1A1917 (표 용지), ink #EDE9E2, ink-muted #A19C93, rule #3B3833.
         stamp(코발트) #8FB2EE 은 목표 휴게소, 목표 %, 경유지로 수락 버튼, 도장에만. on-stamp #0F1A2E.
         warn(호박) #E8AE4A 은 경고에만, 늘 삼각형 글리프 + 문장.
         한글 Wanted Sans 600/700/800, 측정값 Geist Mono 500/600 (단위는 Sans).
         Figure Monumental mono 600 220px -4% tracking, Figure Large mono 600 120px,
         Figure Medium mono 500 64px, 라벨 Sans 600 30px muted, Display Sans 800 88px.
         그림자·글로우·그라데이션·이모지 없음. 칸은 2px rule 괘선, 절취선은 대시(28 on / 20 off) + 반원 노치.
OBJECTS: 통행권(표 용지 + 절취선 노치), 구간 띠(지나온 길 실선, 남은 길 점선, 휴게소 원),
         20칸 충전 게이지, 이중 테두리 도장(-6도), 영수증(점선 리더), 커서(흰 화살표).
MOTION:  도착 expo.out / power4.out, 이동 power3.inOut, 퇴장 power3.in.
         도장만 튐: 1.35 -> 1.0, 0.26 s, 0.09 s 페이드 후 (앱과 동일).
         버튼 누름 0.98, 0.1 s. 숫자 카운트는 linear 정수 스텝.
         글자는 내려앉으면 멈춘다. 떠다니기·숨쉬기·클릭 링 없음.
SAFE:    모든 글자와 제품은 y 168~1330 안. 자막 바는 1170~1300. 1330 아래는 바탕만.
