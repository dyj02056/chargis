> 심사 항목(차량 특화성, 창의성, 기술 활용성, 사업성) 순서로 썼습니다. **기술 활용성은 Pleos SDK/API와 차량 데이터만 평가**하므로(운영사무국 답변 2026-10-28) 공공데이터는 보조로만 적었습니다.
> 숫자 가운데 **[추정]** 표시가 있는 것은 공개 자료에 가정을 더한 값입니다. 실제 사용자, 실측 성과, 제휴는 아직 없으며 만들어 내지 않습니다.

## 1. 앱 이름과 한 줄 소개

**Chargis(차지스): 고속도로 충전 통행권**
전기차로 장거리를 갈 때 "어느 휴게소에서, 몇 %까지, 얼마 동안" 충전하면 되는지 차량 화면이 먼저 알려 주고, 충전기 시간 제한까지 챙기는 Pleos Connect 장거리 충전 비서.

- 팀명: JSW_Lab
- 메일 제목: `[차량용 앱 개발 공모전] Chargis_JSW_Lab_대표자명`

## 2. 문제 정의 (창의성: 페인포인트)

명절이나 주말에 고속도로로 장거리를 가는 전기차 운전자는 매번 같은 고민을 합니다.

| 순간 | 페인포인트 |
|---|---|
| 출발 전·주행 중 | 몇 %까지 채워야 목적지까지 가는지 판단하기 어렵다. 그래서 습관처럼 80%까지 채우고, 감속 구간에서 시간을 버린다 |
| 휴게소 도착 | 충전기가 붐벼서 기다린다. 다음 휴게소가 나은지 알 수 없다 |
| 충전 중 | 충전기마다 다른 **시간 제한**(예: 1회 40분)을 몰라 목표 전에 충전이 끊긴다 |
| 동승자 | 언제 출발하는지 몰라 휴게소에서 계속 묻는다 |

**근거(공개 자료)**
- 전기차 누적 등록은 2026년 6월 말 약 109만 5천 대로, 6개월 사이 약 19만 6천 대(21.8%) 늘었습니다([국토교통부 자동차등록통계 보도](https://mobile.newsis.com/view/NISX20260729_0003728744)).
- 2025년 추석 연휴에 고속도로를 오가는 전기차는 약 170만 대로 전망됐지만, 휴게소 충전기는 211개소 1,590기였습니다([매일신문 2025-10-03](https://www.imaeil.com/page/view/2025100313482104303)).
- **같은 노선에서도 일부 휴게소에만 차가 몰립니다.** 2026년 설 연휴 영동고속도로 인천 방향에서 용인휴게소 충전기 이용률은 46.8%, 여주휴게소는 44.1%였지만, 같은 방향 문막휴게소는 13.7%였습니다. 오후 12~6시 평균 이용률은 충전기 2기 이하 거점이 50.3%, 7기 이상 거점이 33.5%였습니다. 기사는 운전자가 인근 충전소 이용 상황을 미리 확인하게 하는 조치가 필요하다고 봤습니다([아이뉴스24 2026-09-25](https://inews24.com/view/2009015)). Chargis의 혼잡 비교(F1)가 바로 이 문제를 겨냥합니다.
- 그래서 정부는 명절마다 이동형 충전기를 휴게소에 따로 배치합니다([보도](https://biz.sbs.co.kr/amp/article/20000291402)).

**기존 내비와의 차이:** 경로상 충전소 추천과 도착 배터리 예측은 순정 EV 내비와 여러 지도 앱이 이미 합니다. Chargis는 그 경로 위에서 **얼마나·얼마 동안 충전할지**, **충전기 시간 제한**, **혼잡할 때 대기 대 도착 배터리 비교**, **동승자용 출발 예정 시각**을 맡습니다. 경로 안내는 순정 내비에 맡기고 그 위에서 함께 동작합니다.

## 3. 해결 방법과 핵심 기능

| ID | 기능 | 설명 |
|---|---|---|
| F1 | 경로상 충전소 추천 | 충전소마다 주행·도착 시점 예상 대기·충전·들르는 시간을 더해 **목적지에 가장 빨리 도착하는 곳**을 1순위로 고릅니다. 한 번으로 못 가면 두 번째 충전소까지 계획합니다. 휴게소·쉼터를 먼저 고르고, 붐비면 경로를 조금 벗어난 충전소도 왕복 우회까지 계산해 비교합니다 |
| F2 | 목표 충전량 코치 | 목적지까지 필요한 에너지에 안전 마진 15%와 도착 잔량 10%를 더해 "50%까지"처럼 5% 단위로 안내합니다. 기온, 실측 전비, 오르막·내리막을 반영합니다 |
| F3 | 충전 시간 제한 알림 | 제한 안에 목표에 닿을지 미리 계산합니다. 못 닿으면 10분·5분 전에 "종료 시 약 43%"를 경고하고, 끊기면 다음 충전소를 다시 추천합니다 |
| F4 | 경유지 자동 추가 | [경유지로 수락] 한 번으로 순정 내비에 경유지를 넣고 다시 탐색합니다 |

## 4. 차량 특화성 (모바일과 다른 가치)

- **차가 먼저 말한다:** 운전자가 앱을 열지 않아도, 차량 배터리와 경로를 읽어 충전이 필요해지는 순간 음성으로 안내합니다. 모바일 앱은 운전 중에 조작할 수 없습니다.
- **주행·정차 맥락에 따라 화면이 바뀐다:** 주행 중에는 카드 1장, 큰 버튼 2개, 음성만 씁니다(Distraction Optimization 선언, CarUxRestrictions 반영). 기어를 P로 바꾸면 상세 화면이 열리고, 충전 스위치가 켜지면 충전 화면으로, 충전을 마치고 D로 바꾸면 다시 주행 안내로 넘어갑니다. 버튼을 누르지 않아도 차량 상태만으로 흐름이 이어집니다.
- **동승자가 함께 보는 화면:** 충전 중에는 큰 숫자로 목표까지·제한까지 남은 시간과 출발 예정 시각을 보여 줍니다.
- **차량 내비와 한 몸:** 별도 지도 없이 순정 내비에 경유지를 넣고, 순정 내비의 실제 도로 거리로 계산을 고칩니다.

## 5. 개발 계획과 SDK/API 사용 계획 (기술 활용성)

### 5-1. Pleos SDK 사용 (구현 완료, Pleos Connect 에뮬레이터 v2.1.0에서 확인)

| SDK | 쓰는 API | 핵심 기능과의 연결 |
|---|---|---|
| **Vehicle 2.3.2** | EV 배터리 SoC 알림, 기어, 충전 스위치 | 출발 배터리(F1·F2), P/D에 따른 주행·정차 전환, 충전 스위치로 충전 시작·종료(F3) |
| **NaviHelper 3.0.5** | `addWaypoint`·`removeWaypoint`·`requestReRoute`, `requestTrip`, `getCurrentLocationInfo` | 수락한 충전소를 순정 내비 경유지로 추가(F4), 가까운 충전소 3곳의 실제 도로 거리·도착 시간으로 순위 보정(F1) |
| **TextToSpeech 3.3.1** | On-device `speak`·`stop`, 이벤트 리스너 | 추천·경유지·시간 제한 경고 등 모든 안내를 차량 오디오로(주행 중 화면 대신 음성) |
| **SpeechToText 3.3.1** | On-device `request`·`stop`, 결과 리스너 | "수락", "다음", "충전 시작", "출발" 음성 명령 |
| AAOS CarUxRestrictions | 주행 중 화면 제한 | 주행 중 정차 화면 가림 |

- 퍼미션: `CAR_ENERGY`, `CAR_DRIVE`, `NAVI_ROUTE`, `NAVI_ROUTE_SEARCH`, `TTS_SERVICE`, `STT_SERVICE`. 개발 단계에서는 선언만으로 쓰고, M마켓 배포 때 승인 범위를 맞춥니다.
- 차량 제어 SDK가 공개되면 **배터리 예열**(겨울철 충전 시간 단축)을 앱에서 켤 수 있게 합니다. 지금은 예열 효과를 계산해 "차량 화면에서 켜면 약 N분 빨라집니다"라고 안내합니다.

### 5-2. 구현 방법

- Kotlin + Jetpack Compose, minSdk 28, Gradle 8.14.
- 추천 엔진은 안드로이드 의존이 없는 순수 Kotlin이고, SDK는 포트·어댑터 구조로 분리했습니다. 같은 엔진이 데모 시뮬레이터와 Pleos 에뮬레이터에서 그대로 돕니다.
- 데모 시나리오 6개(S1 기본, S2 명절 혼잡, S3 충전 시간 제한, S4 겨울·예열, S5 휴게소 밖 충전, S6 산길). 테스트 125개를 GitHub Actions에서 푸시마다 실행합니다.
- 보조 데이터: 환경부 공공 충전소 API 어댑터와 키를 숨기는 중계 서버(실제 키 검증 전), 데모용 가상 충전소 데이터.

## 6. 사업성

### 6-1. 타깃 고객

| 구분 | 고객 | 이유 |
|---|---|---|
| 1차 | Pleos Connect가 탑재된 현대차·기아·제네시스 **전기차로 고속도로 장거리를 가는 운전자** | 명절·주말·여행 때 충전 고민이 가장 크고, 순정 내비와 차량 데이터를 쓸 수 있다 |
| 2차 | 동승 가족 | 충전 중 출발 예정 시각을 함께 본다 |
| 3차 | 업무용 장거리 EV(영업·출장 차량) | 이동 시간이 곧 비용이라 "목적지 도착 시각 최소화"의 가치가 크다 |

### 6-2. 사용자 규모 [추정]

공식 탑재 대수가 공개되지 않아, 아래 식으로 계산하고 값은 공개 자료가 나오는 대로 바꿉니다.

```
MAU ≈ Pleos Connect 탑재 EV 수 × 앱 설치율 × 월 1회 이상 장거리(100km+) 주행 비율
```

- 예시[추정]: 탑재 EV 10만 대 × 설치율 10% × 장거리 비율 40% ≈ **월 4,000명**. 명절이 있는 달은 장거리 비율이 크게 올라 MAU가 몇 배가 됩니다.
- 국내 전기차는 2026년 6월 기준 약 110만 대이고 반년에 20만 대 가까이 늘고 있어([국토교통부 통계 보도](https://mobile.newsis.com/view/NISX20260729_0003728744)), 탑재 차종이 늘수록 모수가 커집니다.

### 6-3. 지속 사용과 확대

- **사용 패턴:** 매일 쓰는 앱이 아니라 **장거리 이동마다 쓰는 앱**입니다. 그래서 리텐션은 "장거리 이동 가운데 Chargis를 켠 비율"로 잽니다. 장거리 주행을 감지하면 차가 먼저 안내하므로, 앱을 기억하지 않아도 다시 쓰게 됩니다.
- **목표 지표[추정]:** 장거리 이동 재사용률 60% 이상, 추천 수락률 50% 이상, 시간 제한으로 끊긴 충전 비율 감소.
- **확대:** ① 충전 운영사(CPO)와 실시간 가용·시간 제한·요금 데이터 제휴 ② 휴게소 충전 대기 시간에 맞춘 식음료 주문·픽업 연계 ③ 업무용 차량 관리자용 충전 리포트 ④ 해외(Pleos 지원 지역) 고속도로 충전망으로 확장.
- **수익 모델 후보:** 기본 기능은 무료로 둡니다. 제휴 충전소 노출이나 대기 시간 연계 서비스 수수료를 검토하되, **추천 순위는 목적지 도착 시각으로만 정하고 광고로 바꾸지 않습니다**(신뢰가 핵심 가치).
