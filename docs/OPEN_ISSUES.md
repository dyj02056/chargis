## 사용자 결정 필요
- Pleos Connect 에뮬레이터 이미지(AVD) 설치: 공모전 제공 이미지를 받아 Android Studio에 등록해야 에뮬레이터 시연이 가능하다.
- `scripts/check_privacy.sh`의 검사 패턴(실명·전화번호·이메일)을 로컬에서 채워야 한다.
- 현재 화면 확인은 일반 Android 에뮬레이터(`chargis_wide`, API 35 태블릿 가로형)로만 했다. Pleos Connect 에뮬레이터 이미지에서 다시 확인해야 한다.
- 시연 영상 구성: F3 제한 알림은 S3 시나리오에서만 나온다. 3분 영상에 S1과 S3를 어떻게 나눠 담을지 결정이 필요하다.
- 공공 충전소 API 키를 발급받아 실제 응답 필드(statId, chgerType, output, stat, limitYn/limitDetail, kind/kindDetail, useTime, parkingFree, note 등)가 어댑터 가정과 맞는지 확인해야 한다. 특히 ① limitDetail이 이용자 제한 사유인지(시간 제한 문구가 들어오는 경우가 있는지), ② 시설 구분 코드표(C001/C002/C003 등)와 빼기로 한 20개 소분류가 맞는지, ③ 휴게소 충전기의 시간 제한이 어느 필드에 오는지(없으면 운영사 정보 `getChargerOperatorInfo`나 별도 자료가 필요) 확인한다.
- 내비 SDK에서 경로 폴리라인을 받으면 직선 투영을 바꾼다. 지금은 반대 방향 휴게소와 IC에서 들어가기 어려운 국도변 충전소를 가려내지 못하고, 우회 거리도 직선 옆 거리 × 1.3으로 어림한다. 실제 경로에서 충전소까지 도로 거리(왕복)를 받을 수 있는지 확인해야 한다.
- 휴게소 밖 충전소의 가정값(진출입 5분, 휴게소 아닌 곳 순위 가산 5분, 경로 이탈 기준 편도 0.5km, 도착 후 30분 영업)은 실제 주행 자료로 다듬어야 한다. 운전자가 휴게소만 보고 싶을 때 끌 수 있는 설정이 필요한지도 정해야 한다.
- S5 시나리오(휴게소 밖 충전)는 스크린샷이 없고, 기존 스크린샷은 "다음 휴게소" 버튼 문구가 바뀌기 전 화면이다. 다시 찍어야 한다.
- 음성 명령(AndroidSpeechStt)은 에뮬레이터에서 마이크 입력으로 확인하지 못했다. 실기기나 Pleos STT SDK에서 확인이 필요하다. TTS가 말하는 동안 인식기가 그 소리를 듣지 않는지도 봐야 한다.
- 스크린숏 02·04·05·07·08·11은 고도화 전 화면이다(구성은 같고 세부가 조금 다르다). 시연 영상 전에 다시 찍는 것이 좋다.
